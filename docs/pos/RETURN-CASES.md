- Canonical original bodies are reviewed and staged durably before dispatch.
  Recovery looks up the same operation first; no changed command, actor or ID is
  substituted. Explicit result ACK navigates to the actual case, not a fake sale.
- Intake/evidence/qualification use RETURN_CLAIM/PERFORM on the case. Acceptance
  uses RETURN_ACCEPT/PERFORM on the immutable original sale; it is not a case-ID
  or branch-wide grant. No action-approval provenance is fabricated.
- Own-case, receipt, event and financial paging bind their source revisions.
  A changed source requires restart; duplicate/out-of-order/mismatched pages are
  rejected. A missing source or capacity refusal is never a completed/zero record.

  case reads. Financial detail is separate so denied/unavailable financial reads
  cannot hide the recorded legal claim.

  pages with a256-portion ceiling, not an unbounded legacy aggregate fallback.
