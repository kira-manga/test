# Qualified unpriced arrival: bounded rule matching v1

Five frozen requirement cases for #52. **All application execution is NOT_RUN.**
This additive packet preserves earlier purchasing and documentary expectations.

The first target is a shared, rejection-only constraint matcher. It receives one
explicitly selected complete signed-rule body; expected policy/publication and
branch coordinates; authoritative supplier/product/catalog snapshots; independently
ordered operation-bound selected manifests and corresponding resolved current
original metadata; selected retention coordinates; an actual public `PERFORM`
`AuthorizedAction`; an independently expected operation-bound
`AuthorizationRequirement`; and the exact original requester identity. It reports
a mismatch when these constraints disagree.
`NO_MISMATCH` means only that the supplied constraints agree. It grants no authority,
qualifies no original, consumes no approval and produces no business effects.

Fixture symbols are semantic binding labels, not invented wire enum values or
constructors. Wiring must map them to published contracts without changing the
expected outcomes. Actual requester, approver, employee-policy revisions, approval
ID and requirement come from the real public evaluator/approval output. The proof's
requester must equal the independently expected original requester; a proof cannot
choose another originating account. A body claim of the same identities is not a
substitute. All present actors need their separate current Master grants outside
this helper.

Company scope and retention-policy provenance/scope are required whole-action
constraints. Their public bounded-field bindings are unconfirmed in this packet;
fixture fields do not establish such bindings. They remain production/unbound
refusal gates in QAM-05, rather than matcher coverage claims.

The following bindings remain **NOT_RUN**: authenticated signed publication and
current original-source loading; activated policy/catalog/supplier state; current
requester/approver/session/device checks and approval expiry/consumption; exact
durable original bytes and manifests; selected retention-policy installation;
immutable qualification-use history and supported historical readers; genuine
atomic arrival/result/audit/journal/outbox integration; local RPC, restart and
native storage/backup. No accepting default or inferred deadline closes a gap.

Shared matcher cases are platform-independent. Genuine non-device persistence,
authorization and local RPC integration remains a separate required lane. Native
Windows/macOS/Android/iPhone/iPad Master/client variants require their actual
adapter, minimum OS and runtime bindings; all remain NOT_RUN. Central work remains
held, and this packet establishes no implementation closure or owner acceptance.
